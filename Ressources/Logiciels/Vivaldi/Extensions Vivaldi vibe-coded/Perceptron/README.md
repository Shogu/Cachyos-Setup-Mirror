# Extension Vivaldi — Perceptron

Extension compagnon de **Perceptron / OpenCode**.

Elle transmet le contexte du navigateur vers **une nouvelle session dédiée dans Perceptron** :

- le bouton de la barre d’outils : l’URL de l’onglet courant, enrichie de la sélection de texte le cas échéant ;
- le menu contextuel **« Analyser la page avec Perceptron »** (clic droit sur une page) : l’URL de la page ;
- le menu contextuel **« Envoyer la sélection vers Perceptron »** (texte sélectionné) : la sélection.

L’entrée « Envoyer le lien » n’est pas proposée : l’envoi d’un simple lien vers le protocole natif n’est pas pris en charge.

L’archive [vivaldi-perceptron-1.2.zip](vivaldi-perceptron-1.2.zip) est conservée dans ce dossier. Décompresser l’archive, puis charger le dossier extrait depuis `vivaldi://extensions` en mode développeur.
