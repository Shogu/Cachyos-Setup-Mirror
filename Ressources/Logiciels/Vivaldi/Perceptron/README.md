# Extension Vivaldi — Perceptron

Extension compagnon de **Perceptron / OpenCode**.

Elle permet de transmettre le contexte du navigateur vers **une nouvelle session dédiée dans Perceptron** :

- l’URL de l’onglet courant ;
- une sélection de texte dans la page.

Les fichiers de l’extension sont à placer dans ce dossier. La procédure de chargement dans Vivaldi, les permissions et les éventuels réglages du protocole de lancement seront documentés à partir du README technique de l’extension.

Voir aussi [13.7 — Perceptron, extension compagnon pour OpenCode](../../../../docs/13-vivaldi.md#137--perceptron--extension-compagnon-pour-opencode) et [11.33 — Perceptron](../../../../docs/11-applications-vibe-coded.md#1133--perceptron--interface-gnome-pour-opencode).
