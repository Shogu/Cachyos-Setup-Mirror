# Radar

Application libadwaita vibe codée de recherche et de visualisation de fichiers construite autour de `fzf`.

**Paquet fourni : `radar-1.4.0-2-any.pkg.tar.zst`.**

## Installation

```fish
sudo pacman -U ./radar-1.4.0-2-any.pkg.tar.zst
```

## Désinstallation

```fish
sudo pacman -Rns radar
```
