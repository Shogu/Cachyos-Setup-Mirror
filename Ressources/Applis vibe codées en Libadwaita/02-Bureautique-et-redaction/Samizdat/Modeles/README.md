# Modèles Samizdat 0.8.0

Le dépôt contient l’archive **`Modèles de cours en docx (Samizdat).tar.xz`**, qui regroupe quatre modèles pédagogiques préétablis :

- `Cours.docx`
- `Page de garde de séquence.docx`
- `Bac blanc Français.docx`
- `Bac blanc Histoire-Géographie.docx`

## Installation des modèles dans Samizdat

1. Télécharger l’archive depuis ce dossier du dépôt.
2. Extraire son contenu (les quatre fichiers DOCX).
3. Ouvrir Samizdat, puis les préférences avec `Ctrl+,`.
4. Utiliser la fonction d’importation de modèle et sélectionner les fichiers DOCX extraits.
5. Si souhaité, définir le modèle de démarrage dans les préférences.

Les modèles importés sont conservés dans `~/.local/share/samizdat/modeles`. Les fichiers présents dans le dépôt ne sont pas importés automatiquement par l’application.
