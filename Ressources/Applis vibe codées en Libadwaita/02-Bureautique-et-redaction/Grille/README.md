# Grille

Visionneuse simple de fichiers tableurs, codée avec **Claude**.

## Paquet à ajouter

`grille-0.1.0-1-x86_64.pkg.tar.zst` est à déposer manuellement dans ce dossier.

## Installation

Depuis ce dossier, après ajout du paquet :

```fish
sudo pacman -U ./grille-0.1.0-1-x86_64.pkg.tar.zst
```

Les formats pris en charge et la commande de lancement restent à préciser à partir du paquet.
