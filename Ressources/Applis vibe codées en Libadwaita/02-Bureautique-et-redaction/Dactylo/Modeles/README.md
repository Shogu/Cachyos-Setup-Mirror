## Installation des modèles dans Dactylo

1. Télécharger l’archive depuis ce dossier du dépôt.
2. Extraire son contenu (les quatre fichiers DOCX).
3. Ouvrir Dactylo, puis les préférences avec `Ctrl+,`.
4. Utiliser la fonction d’importation de modèle et sélectionner les fichiers DOCX extraits.
5. Si souhaité, définir le modèle de démarrage dans les préférences.

Les modèles importés par l’ancien build sont conservés dans `~/.local/share/samizdat/modeles` ; le chemin du build Dactylo reste à confirmer. Les fichiers présents dans le dépôt ne sont pas importés automatiquement par l’application.
