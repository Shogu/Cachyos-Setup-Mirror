# Decibel

Fork vibe codé de Decibels : ajout de la suppression d’un titre avec `Suppr` et remplacement du morceau dans la fenêtre existante lors de l’ouverture d’un nouveau fichier audio.

**Paquet fourni : `decibel-49.6.1-1-any.pkg.tar.zst`.**

## Installation

```fish
sudo pacman -U ./decibel-49.6.1-1-any.pkg.tar.zst
```

## Désinstallation

```fish
sudo pacman -Rns decibel
```
