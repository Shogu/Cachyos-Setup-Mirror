# UI Management

Extension GNOME Shell maison de **gestion du bureau et des fenêtres**.

## Rôle

UI Management remplace dans ce setup quatre extensions auparavant installées séparément :

- **Just Perfection** — seulement les options réellement utilisées ;
- **AutoActivities** ;
- **Hot Edge** ;
- **Quick Close Overview** / Middle Click to Close in Overview.

Le but est de réduire le nombre d’extensions et la maintenance, sans fusionner des fonctions sans rapport.

## Compatibilité

- GNOME Shell **49**
- GNOME Shell **50**
- GNOME Shell **51**

Catégorie prévue dans Extension Manager Ogu : **Bureau et fenêtres**.

La description doit contenir l’expression **Gestion du bureau et des fenêtres** afin d’être reconnue automatiquement par le classement du gestionnaire.

## Préférences

La version de travail est organisée en quatre pages :

- **Visibilité**
- **Comportement**
- **Personnaliser**
- **Automatisation**

Les blocs **Auto Activities**, **Hot Edge** et **Quick Close in Overview** restent indépendamment activables.

Après migration, les extensions suivantes ne doivent plus être listées comme dépendances séparées du setup :

- Just Perfection
- AutoActivities
- Hot Edge
- Quick Close Overview

**Focus & Boutons**, **Power Total**, **Session Keeper** et **Musicäa** restent séparées.
