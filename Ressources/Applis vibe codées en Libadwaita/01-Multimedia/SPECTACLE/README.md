# SPECTACLE

**SPECTACLE** est un lecteur YouTube qui permet de suivre un contenu **avec ou sans vidéo**. Il propose également une fonction appelée **Rideau**.

## Ressources

Le paquet de l’application et, le cas échéant, ses sources pourront être déposés manuellement dans ce dossier.

Les informations détaillées sur les commandes, les dépendances et la procédure d’installation seront ajoutées à partir du README technique de l’application.
