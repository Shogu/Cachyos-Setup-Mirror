# Fisherman

![Interface de Fisherman](../../screenshots/vibe-coded/fisherman.png)


Application vibe codée en Libadwaita pour gérer les fichiers de configuration de Fish, notamment `config.fish` et les fonctions.

**Paquet fourni : `fisherman-0.3.1-6-any.pkg.tar.zst`.**

Le paquet a été reconstruit le 14/11/2026 avec un contenu identique : il contenait deux `.PKGINFO`, ce qui doublait les dépendances dans pacman. Packager : Ogu.

## Installation

```fish
sudo pacman -U ./fisherman-0.3.1-6-any.pkg.tar.zst
```

## Désinstallation

```fish
sudo pacman -Rns fisherman
```
