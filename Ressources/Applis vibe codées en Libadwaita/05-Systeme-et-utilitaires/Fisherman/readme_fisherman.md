# Fisherman

![Interface de Fisherman](../../screenshots/vibe-coded/fisherman.png)


Application vibe codée en Libadwaita pour gérer les fichiers de configuration de Fish, notamment `config.fish` et les fonctions.

**Paquet fourni : `fisherman-0.1.8-2-any.pkg.tar.zst`.**

## Installation

```fish
sudo pacman -U ./fisherman-0.1.8-2-any.pkg.tar.zst
```

## Désinstallation

```fish
sudo pacman -Rns fisherman
```

## Révision 0.1.8-2

Nouvelle icône poisson inspirée de Fish, en PNG transparent 512 × 512 installé dans hicolor. Le code de la version 0.1.8 est conservé.
