# Pacto

Application vibe codée GTK4/libadwaita pour gérer les fichiers `.pacnew` et `.pacsave` : collecte, tri, édition, comparaison, remplacement et suppression.

**Paquet fourni : `pacto-1.0.0-1-any.pkg.tar.zst`.**

## Installation

```fish
sudo pacman -U ./pacto-1.0.0-1-any.pkg.tar.zst
```

## Désinstallation

```fish
sudo pacman -Rns pacto
```
