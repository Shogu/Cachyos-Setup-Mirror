# Pacto

Application vibe codée GTK4/libadwaita pour gérer les fichiers `.pacnew` et `.pacsave` : collecte, tri, édition, comparaison, remplacement et suppression.

**Paquet fourni : `pacto-1.0.0-8-any.pkg.tar.zst`.**

Le paquet a été reconstruit le 14/11/2026 avec un contenu identique : il contenait deux `.PKGINFO`, ce qui doublait les dépendances dans pacman. Packager : Ogu.

## Installation

```fish
sudo pacman -U ./pacto-1.0.0-8-any.pkg.tar.zst
```

## Désinstallation

```fish
sudo pacman -Rns pacto
```
