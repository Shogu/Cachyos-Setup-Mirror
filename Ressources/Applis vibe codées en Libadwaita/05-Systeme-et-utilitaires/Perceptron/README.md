# Perceptron — variante WebKit

Perceptron est une interface GTK4/libadwaita pour [OpenCode](https://opencode.ai). Elle démarre `opencode serve`, effectue l’appairage avec `opencode pair`, puis affiche l’interface web d’OpenCode dans une vue **WebKitGTK 6.0**. OpenCode doit être installé séparément et accessible dans le `PATH`.

## Extension compagnon Vivaldi

Une extension pour Vivaldi permet d’envoyer l’URL de l’onglet courant ou une sélection de texte vers **une nouvelle session dédiée dans Perceptron**. Les fichiers de l’extension sont prévus dans [Ressources/Logiciels/Vivaldi/Perceptron](../../../Logiciels/Vivaldi/Perceptron/README.md).
