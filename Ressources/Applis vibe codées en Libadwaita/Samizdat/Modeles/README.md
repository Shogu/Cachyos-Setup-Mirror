# Modèles Samizdat 0.8.0

Ajouter manuellement ici les quatre fichiers DOCX fournis avec Samizdat 0.8.0 :

- `Cours.docx`
- `Page de garde de séquence.docx`
- `Bac blanc Français.docx`
- `Bac blanc Histoire-Géographie.docx`

Dans l’application, le dossier utilisateur de modèles est `~/.local/share/samizdat/modeles`.
