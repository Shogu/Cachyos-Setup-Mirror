# Icônes UI

Application Python/GTK4 pour gérer les icônes couleur et symboliques des applications installées.

Le fichier exécutable `icones-ogu.pyz` et le document d’utilisation `LISEZMOI.md` de l’archive fournie sont à ajouter manuellement dans ce dossier.

Lancement depuis ce dossier :

```fish
python3 icones-ogu.pyz
```

Dépendances éventuelles :

```fish
sudo pacman -S python-gobject gtk4
```

Cette application ne gère pas les icônes PLACES des dossiers personnels. Le gestionnaire PLACES est un outil séparé, dont l’archive reste à recevoir.
